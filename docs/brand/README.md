# The spillpoint logo

The mark, the wordmark, and the two side by side, the lockup. Every file here, and the page's two icons, is exactly as Claude Design exported it: nothing is optimized, re-exported or edited. Each keeps its content-credentials block, which records how it was made. To change one, make it again rather than editing it.

## The rules

- **The mark is always in color, or on its navy tile.** Anything in one color uses the wordmark alone.
- **`mark.svg` and `lockup-light.svg` are for light backgrounds.** On dark, use `lockup-dark.svg`, or the mark on its tile: the page's icon, `apps/dashboard/public/favicon.svg`.
- **Colors:** navy `#1d3557`, teal `#2a9d8f`, and white.
- **Type:** IBM Plex Sans SemiBold. The letters are outlined in the SVGs, so no font is needed.

## The files

| File | What it is | For |
|---|---|---|
| `mark.svg` | The mark, navy and teal | Light backgrounds |
| `lockup-light.svg` | The mark and the wordmark, navy and teal | Light backgrounds. The root README shows it in light mode. |
| `lockup-dark.svg` | The mark and the wordmark, white and teal | Dark backgrounds. The root README shows it in dark mode. |
| `wordmark-plain-navy.svg` | The wordmark alone, navy | One color, on light |
| `wordmark-plain-white.svg` | The wordmark alone, white | One color, on dark |

| `apps/dashboard/public/favicon-32.png` | The same, 32 × 32 | The page's icon, in browsers without SVG icons |
