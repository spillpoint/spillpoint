# Edge case 4: one series, participating and capped

This is the same company as edge case 2. One term changes: Seed Preferred is **participating, capped at 3x its original issue price in total**. The preference counts toward the cap. The cap is hit, then the series converts.

| Holder | Security | Shares |
|---|---|---:|
| Founder A | Common | 6,000,000 |
| Founder B | Common | 2,000,000 |
| Investor X | Seed Preferred | 1,500,000 |
| Investor Y | Seed Preferred | 500,000 |

Seed Preferred terms:
- original issue price $1.50
- 1x preference ($3,000,000)
- participating, with total return capped at 3 × $1.50 × 2,000,000 = $9,000,000
- conversion 1:1

The exit range and exit values are the same as edge case 2.
